# 23. Messages explained

SHOBS-P talks to you in five places:

- **The status bar** at the bottom of the window: the latest news, one line. While SHOBS-P works, the busy bar at its
  left end says what it is doing (chapter 3). While a job runs, a ⚠ or ✖ stays on the status line until the job
  ends, so a later routine line never hides it. When the job ends, the line says how it went: the one ⚠ or ✖ itself,
  or *⚠ N things need a look (click to see them)* when there were several (or *✖ … (and N more: click to see them)*).
  After a report save it also holds a button for the upload page.
- **The Findings list** (from 2.4.0): every ⚠ and ✖ written to the log, kept until you tick it off or run that step again, with what
  to do in the words of this chapter. The **⚠ N to look at** link at the right end of the status line opens it
  (chapter 3).
- **The log**: on the Calibrate page, and under the image on the Photometry page (**Show log** / **Hide log**; hidden until you press **Show log**, from 2.4.0). Every
  status line goes here too, often with more detail, and so do the routine notes that never reach the status line.
  It is the full record for troubleshooting; anything that needs you is also on the Findings list. In the log file
  (chapter 22) a ⚠ line is tagged `[WARN]` and a ✖ line `[ERROR]`, so they are easy to search for.
- **Message boxes**: a question (Yes / No, sometimes Cancel) when SHOBS-P needs a decision, a warning when it found a
  problem, an error when it cannot go on.
- **Notes and cautions on the Output pages**: lines starting with **⚠** are cautions about the result.

**What the signs mean** (from 2.3.6, the same everywhere):

- **⚠** something needs a look, and probably an action, before you trust or send the result. SHOBS-P keeps ⚠ for
  that; it is never used for routine news.
- **✖** something stopped or failed: a step did not run, a file was not saved, a lookup gave up.
- **✔** a step is done as you asked.
- **No sign**: a plain note. It is there for the record; nothing needs doing.

A photometry run's ⚠ and ✖ lines travel with the result. The settings file saved beside a report lists them under
*Findings from the photometry run …* (from 2.4.0 a line that came up more than once in the run is listed once), and the report's notes say how many there were (for example *2 findings from
the run, see the settings file*; in a Variables AAVSO report the comma becomes a semicolon), so whoever reads the report later sees them too. A
report that covers several nights carries that note only on the rows of the night the run reduced; the other nights' rows
leave it out.

![A warning box after photometry](img/23-edge-caution.png)

Every question has the safe choice as its default (from 2.3.5): the button that Enter presses is **No**, **Stop**,
**Cancel** or **These frames only**, never the risky one. Some questions have buttons that say what they do instead of
Yes and No. Read the whole message before you answer. The messages
below are the ones new users meet most often, grouped by step. "…" stands for the names and numbers filled in.

## Setting up (Windows, Linux, Mac)

These appear in the console window of **Create shortcuts.bat** (Windows) or the Terminal window the first time
SHOBS-P starts (Linux, Mac); see chapter 2. From 2.3.5 the three systems say the same things.

| Message | What it means | What to do |
|---|---|---|
| *Looking for a Python that can run SHOBS-P...* then *Trying …* and *usable: Python 3.13.x* or *not usable: …* | SHOBS-P checks each Python it finds, 3.13, 3.12 and 3.11 first. | Nothing; it picks the first one that works. |
| *Python 3.15.x: some packages SHOBS-P needs have no ready-made copy for it yet (they would have to be compiled, and SHOBS-P never compiles).* *Trying the next Python.* | A brand-new Python has no ready-made packages yet. | Nothing, if another Python follows. Otherwise install Python 3.13 (Mac: 3.14). |
| *✔ SHOBS-P is set up with Python 3.13.x.* | The setup worked. | Nothing; SHOBS-P opens. |
| *✖ SHOBS-P could not find a Python it can use (each one tried is listed above, with the reason).* | No Python 3.11 or newer with Tkinter was found. | Windows: install Python 3.13 from python.org (tick **Add python.exe to PATH**).
